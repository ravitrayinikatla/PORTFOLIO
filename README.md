## 🛠️ Setup & Usage

### Quick Start

1. **Clone the repository**
```bash
   git clone https://github.com/ravitrayinikatla/PORTFOLIO.git
   cd PORTFOLIO
```

2. **Open in browser**
   - Simply open `index.html` in your web browser
   - Or use a local server for better experience:
```bash
   python -m http.server 8000
   # Then visit http://localhost:8000
```

3. **Deploy to GitHub Pages**
   - Push to your repository
   - Go to Settings > Pages
   - Select `main` branch as source
   - Your portfolio will be live at `https://yourusername.github.io/PORTFOLIO/`

## 🎨 Customization

To personalize this portfolio:

1. **Update Personal Info** (lines 1097-1102)
   - Name, title, location, phone
   - Social links (GitHub, LinkedIn, Email)

2. **Modify Colors** (lines 17-28 in CSS)
   - Change `--accent-cyan`, `--accent-purple`, `--accent-orange`
   - Adjust `--bg-dark` and `--bg-darker` for different themes

3. **Edit Content Sections**
   - About section (search for "About" in HTML)
   - Update project cards with your own work
   - Add/remove certifications as needed

4. **Replace Images**
   - Add your profile image to the hero section
